# Fisher-Glass Learning: Classification Bounds and Subpopulation Audits

This is the **camera-ready-v22** reproducibility release for the final paper. The versioned artifact is [camera-ready-v22 on GitHub](https://github.com/E-zClap/fisher-glass-learning/releases/tag/camera-ready-v22); the [repository](https://github.com/E-zClap/fisher-glass-learning) contains the same code and retained numeric inputs. Start with [START_HERE.md](START_HERE.md) for the standalone supplement, final paper, replay commands, and evidence limits. Use the versioned release when citing or reproducing the reported results.

The final main PDF has 48 pages: ten pages of main text and the funding/competing-interest statement, two reference pages, 28 scientific appendix pages, and eight pages of artifact availability/checklist. This v22 release adopts numeric citations and harmonizes bibliography typography and link colors in the final manuscript and standalone supplement, each retaining the complete 30-entry bibliography. The Figure 1 caption, artwork, photographs, geometry, and labels are unchanged. The abstract and competing-interest statement remain unchanged. The supplemental evidence guide includes all nine retained paired failure-prediction intervals. Scientific Appendices A–E, numerical results, and Figure 1's retained matched image pair are unchanged. These changes introduce no new empirical experiments. The general nuisance-admission screen and threshold-based coefficient policy remain unevaluated. The [expanded appendix record](docs/extended_appendix_details/README.md) remains available.

The final manuscript source is `tex/camera_ready_v2/main.tex`. The release includes experiment implementations, per-seed numeric records, compact reanalysis inputs, source/input hashes, and the historical reports for cohorts whose original outputs were not recovered. The two retained composite images used in Figure 1 are included as manuscript illustrations with source identifiers and hashes. Full benchmark datasets, other generated intervention images, image-selection galleries, feature caches, model weights, private machine paths, logs, and old manuscript/build backups are excluded.

## Reproduce the experiments

Two workflows serve different purposes:

- **Independent experiment replication:** follow [the primary-experiment guide](docs/REPRODUCING_PRIMARY_EXPERIMENTS.md) for the five-seed prospective Waterbirds evaluation, hidden-slice discovery and repair, and [the group-free selection guide](experiments/waterbirds_group_free_lambda/README.md) for that extension; follow [the experiment guide](docs/REPRODUCING_EXPERIMENTS.md) for synthetic checks, frozen-feature training, and acquisition. These guides give data preparation and paper-specific commands instead of relying on quick-start defaults.
- **Numerical replay:** the commands below recompute reported analyses from the released retained inputs without retraining. Historical outputs that were not retained can be regenerated by running the experiment code, but their original file contents cannot be recovered from aggregate reports.

The release provides code, protocols, data-access instructions, and rerun commands. Missing historical run files limit exact archival replay; independent replication uses the documented experiment workflows. The guides record which checks were executed and distinguish smoke tests from full experiments.

## Reproduce the retained numerical results

From the repository root, in a Python environment with NumPy and SciPy:

```shell
python -m pip install -r requirements-replay.txt
python scripts/reproduce_retained_tables.py
python scripts/reproduce_w2_audit.py
python reanalysis/flip_prediction/aggregate.py
python reanalysis/four_way_swap/reanalyse.py
python reanalysis/supporting_contrasts/recompute.py
python experiments/prospective_nuisance_shift/make_report.py --out-dir artifacts/prospective_v2 --report build/reproduced_tables/prospective_v2_report.md
```

These commands need no datasets, weights, GPU, or server access. The first script checks the published SHA256 manifest, recomputes 60 matched selector decisions, 40 matrix/seed/group records, and 736 retained hidden-slice/group-free seed summaries, and compares the regenerated main tables with the retained CSVs. The W2 script checks 260 audit rows and 37 aggregate rows. The flip-prediction aggregation verifies all 15 seed/variant records against the archived result. Outputs go under `build/reproduced_tables/`, except the flip-prediction, four-summary, and supporting-contrast exports, which are regenerated in their reanalysis directories.

To refit Table D.7's auxiliary logistic predictors from the original retained donor rows, use a separate environment with the recorded numerical library versions:

```shell
python -m pip install -r reanalysis/flip_prediction/requirements-refit.txt
python reanalysis/flip_prediction/refit.py
```

This refit was checked against every archived metric, with maximum absolute difference `2.73e-12`. See [the detailed flip-prediction protocol](reanalysis/flip_prediction/README.md). It does not retrain the image classifier or score new images.

The worked classification example has a separate deterministic verification command:

```shell
python reanalysis/classification_mechanism/verify.py
```

It checks the information integrals, decision separation, KL inequality, exact excess risk, and binomial identity used by the proof. These checks support the analytic derivation; they are not a new empirical experiment. See [the derivation record](reanalysis/classification_mechanism/README.md).

## Provenance and exact versions

[ARTIFACT_MANIFEST.json](ARTIFACT_MANIFEST.json) identifies every original source archive, its SHA256 and size, each included source member, and the published file SHA256. Original archive hashes identify historical provenance; the original tarballs are not distributed because they mix numeric results with images, logs, caches or fitted coefficients. The release distributes their curated numeric members in the directories above.

Most numeric members are byte-identical to the originals. Six W2 JSON files had private dataset-root paths removed. Hidden-slice and group-free fitted weight/bias arrays were omitted. The manifest records every such transformation and preserves the SHA256 of the original member. Embedded original canonical artifact hashes remain historical identifiers, not checksums of the modified release files. Verify distributed files with:

```shell
python scripts/reproduce_retained_tables.py --verify-only
```

The full hidden-slice aggregator (`experiments/waterbirds_hidden_slice/aggregate.py --out-dir ...`) and group-free aggregator (`experiments/waterbirds_group_free_lambda/aggregate.py --out-dir ...`) are included for **fresh complete pipeline outputs**. They enforce original artifact/model/score integrity. Use the release replay script for the curated retained records, because this release deliberately omits the model and feature artifacts those full aggregators require.

The compact matrix NPZs retain validation rows, labels/group IDs, original standardized coordinates, raw logits, temperature and global task scales. The full redundant feature/score caches are excluded. The flip NPZs retain the numeric donor-row records needed to refit the auxiliary prediction experiment. Neither analysis reconstructs coordinates from aggregate statistics.

## Statistical conventions and scope

Prospective, matched-selector and matrix summaries retain the historical **nominal normal-approximation** interval `mean +/- 1.96 * sample_SD / sqrt(5)`. Corrected hidden-slice and group-free summaries use Student-t intervals across five paired seeds. Per-run cluster bootstrap and the nominal Gaussian/Wald ridge/exact audit address different uncertainty calculations. Acquisition report means have no recovered seed-level intervals. Seed intervals describe fitting/partition variability on a fixed benchmark, not five independent datasets.

Historical reports preserve their original prose and can contain interpretations superseded by the final manuscript. In particular, matched validation accuracy/NLL selectors agree with the original prospective selector in all five seeds, within-slice centering reverses its selection, and the specified predictive-Fisher reanalysis preserves it. The release distinguishes those post hoc analyses from the original prospective selection.
