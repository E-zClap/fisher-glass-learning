# Extended appendix record

These are the expanded appendix sources distributed with camera-ready-v2, preserved while camera-ready-v3 consolidates the scientific PDF. They retain the full intermediate displays, table entries and execution descriptions. They are supporting source records, not a standalone LaTeX document; the current paper remains the authoritative statement and interpretation of results.

Original semantic labels in these files identify the detailed material. The current reproduction guides and ARTIFACT_MANIFEST.json provide executable workflows, input/output paths and hashes. The five redundant appendix figure sources and PDFs remain under tex/camera_ready_v2/figures/.

The [expanded v2 PDF](https://github.com/E-zClap/fisher-glass-learning/releases/download/camera-ready-v2/main.pdf) renders the historical record. The [manuscript map](../MANUSCRIPT_MAP.md) identifies consolidated v3 tables and retained figure assets. All eleven TeX sources here are byte-identical to the corresponding v2 appendix sources.
